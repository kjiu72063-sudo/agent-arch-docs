# 掌握自检

Track C 第三页：**全站唯一口径页**。这里定义两件事——(1) 12 个知识点各自"了解 / 熟悉 / 精通"的可验证判定；(2) 对比矩阵用的 **评分口径常量表**（0–5、能力象限映射），防止各页"各说各话"。

::: tip 一句话
自检不是为了打分而打分，而是确认"你真的能用它做成事"。每一档都对应**可验证的行为**，不是"感觉会了"。
:::

## 通用分档口径

| 档位 | 判定标准 |
|---|---|
| **了解** | 能解释它在一张体系图中的位置 + 说出一个权威出处 + 举一个代表实现 |
| **熟悉** | 能针对真实场景做出一个**可运行、可验证**的东西 |
| **精通** | 能取舍方案、设计实现、识别反模式，并向他人解释为什么 |

## 12 知识点三档 checklist

### Track A 概念（6）
| 知识点 | 了解 | 熟悉 | 精通 |
|---|---|---|---|
| 01 prompt | 说出它是基座 | 能写清 system prompt | 能设计多策略 prompt 体系 |

### Track B 实例（6）
每个实例的"了解/熟悉/精通"见各实例页的"三档自检"表。本页只统一**口径**，不重复评分。

## 评分口径常量表（0–5，全站统一）

> 对比矩阵（compare 页）读取本表，任何一页都不许自己改语义。

| 分数 | 含义 |
|---|---|
| 5 | 同类中最强 / 几乎无短板 |
| 4 | 强，偶有取舍 |
| 3 | 中等，够用 |
| 2 | 偏弱或有明显限制 |
| 1 | 基本不具备该能力 |

**能力象限映射**：
- 横轴（上手难度）：分越高 = 越易上手（5=极易，1=很陡）。
- 纵轴（能力/场景定位）：分越高 = 越强越通用。

::: warning 口径约束
本页常量表是**唯一权威**。若某实例页或对比页的分数与本表语义冲突，以本表为准，并回 [事实源清单](/practice/sources) 复核——这就是"防止漂移"的机制。
:::

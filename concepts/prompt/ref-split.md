# 1-4 · 六大策略 ②③：提供参考文本 + 拆分复杂任务

## 策略② · 提供参考文本

把"参考答案"放进 prompt，让模型基于给定材料作答，而不是凭记忆编造。

- 让模型先引述你提供的资料，再作答（减少幻觉）。
- 适用于"基于文档问答""按样例生成"类任务。

## 策略③ · 把复杂任务拆成简单步骤

模型擅长逐步执行，不擅长一步到位处理长链条。

- 把一个大任务切成多个小步骤，每步单独验证。
- 需要多步推理时，先让模型列计划，再逐步执行。

::: tip 落点
策略②解决"凭空编"，策略③解决"一步崩"。两者都服务于"可控、可验证"——这正是后面 harness / loop 反复强调的工程纪律。
:::

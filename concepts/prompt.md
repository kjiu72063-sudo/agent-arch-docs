# 01 · prompt engineering

> **难度**：1-1~1-5 机制与策略（入门→熟悉） · 1-6 实例对照（熟悉） · 1-7 坑与自检（全档复核）

主轴第一节、整个体系的**基座**：设计进入模型的指令，让 agent 的意图稳定、可控。从"这是什么"讲到"怎么用、怎么避坑"。

::: tip 类比
prompt engineering 就像给"非常聪明但容易误会你的实习生"写任务说明书：写清楚，它就靠谱；写含糊，它就自由发挥。
:::

## 一章看懂它

1. **1-1 入门**：是什么 · 为什么是基座
2. **1-2 system prompt**：常驻说明书怎么运作
3. **1-3~1-5 六大策略**：清晰 · 参考 · 拆 · 想 · 工具 · 测
4. **1-6 实例**：Claude Code / Hermes / DeepSeek Harness 对照
5. **1-7 避坑 + 自检**：常见坑 · 三档判定
